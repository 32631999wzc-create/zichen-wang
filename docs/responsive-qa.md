# 响应式验收标准

## 固定断点

- 手机：视口宽度不大于 `767px`
- 平板：`768px` 至 `1023px`
- 桌面：不小于 `1024px`

CSS 只使用 `767px` 与 `1023px` 两个 `max-width` 布局断点。组件如需流体变化，优先使用 `clamp()`、Grid 和 Flex，而不是增加临时断点。

## 固定检查视口

| 视口 | 代表设备 | 必查内容 |
| --- | --- | --- |
| 360 × 800 | 小屏手机 | 无横向滚动；标题不截断；按钮可点；卡片单列 |
| 390 × 844 | 主流手机 | 导航与联系入口可用；中英文层级清楚；图片不变形 |
| 768 × 1024 | 平板 | 双栏切换合理；留白连续；触控目标不拥挤 |
| 1440 × 900 | 桌面 | 内容不超出最大宽度；首屏比例与案例节奏正确 |
| 1920 × 1080 | 大桌面 | 内容不过度拉伸；背景图形不喧宾夺主；行长可读 |

## 每次发布前

1. 运行 `npm run check:responsive`，确认没有私自增加断点。
2. 运行 `npm run lint` 与 `npm run build`。
3. 在以上五个视口检查首页、关于页、项目列表页和至少一个项目详情页。
4. 使用键盘检查导航、案例卡片和外链焦点；开启“减少动态效果”确认页面仍可用。
